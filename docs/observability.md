# Observability (D5, A6, L5)

| Signal | Implementation |
|---|---|
| Structured logs | JSON on stdout from every service (`observability/logging.py`): `ts, level, service, logger, msg, correlation_id, run_id` + extras |
| Correlation id | `X-Correlation-ID` header accepted/created by the API, stored on the run, restored by the worker, forwarded to the verifier; present in every log line and trace event |
| Tracing | OpenTelemetry -> Jaeger (OTLP/HTTP, `OTLP_ENDPOINT`). The submit span's context is stored with the run so worker spans continue the same trace; httpx instrumentation links worker -> verifier |
| Metrics | Prometheus scrapes api, verifier, every worker replica (DNS service discovery) and cAdvisor |
| Dashboard | Grafana "Food Label Compliance - Service", generated by `deploy/grafana/build_dashboard.py` |
| Run reconstruction | `GET /v1/runs/{run_id}/trace`: every guardrail result, tool call (args, query, returned passage ids), model call (step, latency, tokens, cost, prompt version), verification outcome, route |

## Dashboard coverage

p50/p95 API latency; end-to-end run latency p50/p95; throughput; 5xx error rate; availability (`up`); task success rate; steps and tool
calls per run; latency per step; retry rate; breaker state; queue depth; cost per 100 runs and by step; cache hit rate; quarantined /
rate-limited / guardrail events; live quality scores; index freshness; CPU, memory and uptime per container.

Task success rate = runs that completed without degrading. An escalated run still counts as a success (it is the correct behaviour);
if you want "answered without escalation" as a separate series, add it to `build_dashboard.py`.

## Adding a metric

Define it in `observability/metrics.py`, increment it where the event happens, add a panel to `PANELS` in `build_dashboard.py`, run the
script, commit the regenerated JSON.

## Known limits

cAdvisor needs host access and may expose fewer container labels on Docker Desktop (Windows/macOS); if `name=~".+"` panels are empty,
check `http://localhost:8081/containers/` and adjust the label in `build_dashboard.py`.
